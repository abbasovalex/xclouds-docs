# Что такое xClouds

xClouds — это хаб веб-браузеров и dev-tunnel для ускорения тестирования и разработки вашего сайта/приложения.
Используйте нашу платформу, если вам:
- тесно и неудобно работать с браузерами в локальной среде;
- не хочется поддерживать свой кластер браузеров;
- важнее освободить время devops-инженеров на более приоритетные задачи;
- нужно быстро добавить браузеры под новые проекты для которых ещё нет ресурсов в инфраструктуре компании;
- требуется распараллелить ваши тесты для увеличения скорости CI/CD;
- нужно поддерживать одновременно тесты на разных фреймворках (Seleniumm, Playwright, Puppeteer / CDP);
- надо собирать открытые данные в несколько потоков;
- нужен публичный https домен для тестирования API платежного сервиса или чат-бота. 

##### Подробнее про хаб веб-браузеров
Вам не требуется устанавливать Selenium, Playwright, Puppeteer / CDP. Вместо этого вы подключаетесь к нашей готовой
инфраструктуре по https / wss протоколу. Кроме того, вы не ограничены одним браузером — запускайте параллельно столько браузеров,
сколько необходимо. По умолчанию мы используем полноценные живые браузеры. Они запускаются в виртуальной среде, имеют UI и делают
полный рендеринг страницы. Вы можете использовать наши браузеры для тестирования, сбора открытых данных и подключить их к своим AI-агентам.
Используйте примеры ниже для быстрого подключения и обзора возможностей: 

| Фреймворк       | Точка подключения                                          | Инструкция для подключения            |
|-----------------|------------------------------------------------------------|---------------------------------------|
| Selenium        | `https://selenium.xclouds.dev/wd/hub?api_key=YOUR_API_KEY` | [открыть](/ru/examples/selenium)      |
| Playwright      | `wss://playwright.xclouds.dev/v1.58/?api_key=YOUR_API_KEY` | [открыть](/ru/examples/playwright)    |
| Puppeteer / CDP | `wss://cdp.xclouds.dev/cdp/?api_key=YOUR_API_KEY`          | [открыть](/ru/examples/puppeteer_cdp) |

##### Подробнее про dev tunnel (туннель для разработки)
Туннель требуется когда вам надо безопасно предоставлять доступ к локальным веб-службам через Интернет. К примеру, 
вам надо подключить к своему сайту/приложению платёжный модуль, но он отправляет вам данные через веб-хуки и вам нужен
публичный URI который сможет принимать. Или когда вы
хотите запустить e2e или UI тесты до заливки обновленного кода в ветку своего репозитория. Туннель также выручает, когда
нужно скинуть ссылку клиенту или коллегам для демонстрации промежуточного решения напрямую со своего ПК/ноутбука.
Обратите внимание: туннель используется именно для разработки и тестирования, он не предназначен для нагрузок на живом сайте.

| Команда для запуска                                              | Инструкция для подключения         |
|------------------------------------------------------------------|------------------------------------|
| `xclouds tunnel start --authtoken YOUR_TUNNEL_TOKEN --port 8080` | [открыть](/ru/examples/dev_tunnel) |

## Храните ключи приватно
<p class="tip">
    В примерах используются <strong>YOUR_API_KEY</strong> и <strong>YOUR_TUNNEL_TOKEN</strong>. Их можно получить в личном кабинете после регистрации.
    Ключи не предназначены для посторонних глаз. Для безопасности рекомендуем хранить их в файле .env своего проекта.
</p>
